# Engro PPE (Angular)

Angular port of the Engro Fertilizer PPE Safety Monitor dashboard (same UI/features as the React app).

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:4200](http://localhost:4200).

## Routes

- `/` — Live dashboard
- `/cameras` — Camera wall (13 feeds)
- `/history` — Violation history + filters + Excel export
